管理员能做的是账号与配置， 看不到任何人的提问原文——你现在的 views 是 ， 里面没有 newbie。直接开新人的 memory 接口，服务端照样 403。

少了第二步，改完在前台搜不到，会以为没生效—— 而库里其实已经改了，只是检索还在用旧索引。这种"改了但看不见"最难查。
L3 是干什么用的 L3 的分数上限是 0.45，作答阈值 0.62——结构上过不了。 录进去不是为了让它直接回答，是为了让它能被检索到、然后触发升级给 Mentor。 过期条目同理。
