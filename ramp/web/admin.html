成员 –在线会话 –
怎么加一个人 对方在登录页自助注册（新账号是待激活状态，登不进来）→ 你在下面点「设置」，一次填完角色、团队、岗位、入职日期、Mentor → 点激活。他就能用了。

管理员能做的是账号与配置， 看不到任何人的提问原文——你现在的 views 是 ， 里面没有 newbie。直接开新人的 memory 接口，服务端照样 403。

停用会同时踢掉该账号的在线会话， 不是等它自然过期——否则停用只是个摆设。

新增条目
保存会做两件事 写库 + 立刻重算这条的向量并重建索引。
少了第二步，改完在前台搜不到，会以为没生效—— 而库里其实已经改了，只是检索还在用旧索引。这种"改了但看不见"最难查。
L3 是干什么用的 L3 的分数上限是 0.45，作答阈值 0.62——结构上过不了。 录进去不是为了让它直接回答，是为了让它能被检索到、然后触发升级给 Mentor。 过期条目同理。
四个系统按字段解锁，不是整体开关 转正日期、年假额度、汇报线这些能从入职日期和账号表算出来，永远可用，不用录。
社保、公积金、岗位权限清单要在这里配，配一项解锁一项；没配过的字段 Agent 会诚实说查不到，不会编。

配置里所有的「人」存的都是账号，显示时去账号表解析。 上一版这里存的是名字，于是出现了一个叫「李敏」的审批人—— 而系统里根本没有李敏这个人。名字一旦离开账号表， 就再也没有东西保证它对应一个真实存在的人。
